\section{予備審査の質問と回答}
予備審査では、本研究の手法および位置づけに関して、主に以下の点について質問が挙げられた。
本章では、各質問への回答と、それを踏まえた研究内容の修正点について説明する。

\begin{enumerate}
  \item 自己位置の補完には、どのようなセンサ情報を用いているのか
  \item 画像情報を用いて自己位置推定を行う点でVisual SLAMと類似しているが、本研究手法はどのような点で優れているのか
  \item どういう意味で簡易なモデルなのか
  \item 簡易モデルにおけるワイヤーフレームを自動生成することは可能か
\end{enumerate}


\subsection{自己位置の補完に用いるセンサ情報}
質問1「自己位置の補完には、どのようなセンサ情報を用いているのか」について回答する。

本研究で自己位置の補完に用いる情報は、モバイル端末のVisual-Inertial Odometry (VIO) である。
具体的に用いるセンサ情報は以下の2点である。

\begin{itemize}
  \item \textbf{画像情報}：端末に搭載されたカメラから取得
  \item \textbf{慣性情報}：IMU（加速度計、ジャイロスコープ）から取得
\end{itemize}

VIOは、画像と慣性情報を統合し、端末の位置姿勢を高頻度に推定する手法である。
本研究では実行環境としてARKitを採用している。
ARKitは内部処理で局所的な特徴点マップを構築しており、
モバイル端末単体でのSLAM (Simultaneous Localization and Mapping) に相当する機能を実現している。

ARKitによる推定は端末内処理のみで完結するため、外部インフラを必要とせず高いリアルタイム性が確保される。
一方で、VIOは長時間動作時の累積誤差や、環境特徴が乏しい状況での精度低下が課題となる\cite{AppleARKitWorldTracking}。
本研究の提案手法は、これらを補い、長期的な安定性を担保する位置づけにある。


\subsection{Visual SLAMとの比較および本手法の優位性}
質問2「画像情報を用いて自己位置推定を行う点でVisual SLAMと類似しているが、本研究手法はどのような点で優れているのか」について回答する。

本手法の優位性は、特徴の乏しい環境下における自己位置推定の安定性にある。

まず、単調な壁面が多い屋内環境におけるVisual SLAMの不安定性が課題である。
Visual SLAMは特徴点を追跡して自己位置を推定するが、
テクスチャが乏しい環境では特徴点が十分に検出できずトラッキングが不安定になりやすい。
これに対し、本研究のナビゲーション用途においては、
必ずしも幾何学的に高精度な3次元モデルや精密な自己位置推定が必要とは限らない。
むしろ、空間の大まかな構造を表現した簡易モデルを参照し、
特徴の乏しい環境下でも自己位置推定を安定して継続できることが重要である。

本研究ではこの優位性を検証するため、モバイル端末におけるVisual SLAM相当機能であるARKit (VIO) との比較実験を行った。
ARKitのVIOは、移動量の推定に加え、内部処理で周辺環境の特徴点マップを動的に保持している。
この特徴はVisual SLAMの基本動作と合致するため、本実験ではARKitを比較対象とした。

実験の結果、VIO単独では移動に伴いドリフト現象で位置誤差が増大したのに対し、
提案手法は断続的ながらも、既知の簡易モデルとの照合により安定して絶対位置を推定できた。
しかし、提案手法単独では通信遅延や処理時間によりリアルタイム性が損なわれる課題があった。
そこで、モバイル端末のVIOと提案手法を組み合わせる手法を採用した。
その結果、特徴点が検出されにくい環境下でも、
VIOが移動の連続性を維持しつつ、提案手法が定期的に累積誤差を解消することで、
リアルタイム性と安定性を両立したナビゲーションが実現可能であることを実証した。


\subsection{簡易モデルの定義と意図}
質問3「どういう意味で簡易なモデルなのか」について回答する。

本研究における簡易モデル（図\ref{three}(c)）とは、
計算コストとデータ量を抑えるため、幾何構造を大幅に抽象化したものを指す。

一般に、屋内環境の3次元モデル化には、レーザースキャナによる高密度な点群計測（図\ref{three}(a)）や、
フォトグラメトリによるメッシュ生成（図\ref{three}(b)）が用いられる。
これらは形状を詳細に再現できる反面、データ容量が大きく、モバイル端末でのリアルタイム処理には不向きである。
対して本研究の簡易モデルは、2次元マップに基づく少数の頂点と線分を骨格とし、そこに全方位画像のテクスチャ情報を付与して構成される。
幾何構造を必要最低限に留めることで、ナビゲーションに必要な環境情報を確保しつつ、モバイル端末上で軽快に動作するシステムを実現している。

\subsection{ワイヤーフレーム生成の自動化について}
質問4「簡易モデルにおけるワイヤーフレームを自動生成することは可能か」について回答する。

本研究では、ユーザー入力と自動処理を組み合わせ、半自動的にモデルを生成する手法へ変更した。

具体的には、ユーザーが2次元マップ上でマップと実空間の対応点、および簡易モデルの主要な頂点を指定すると、
システムが以下を自動的に実行する。

\begin{enumerate}
  \item \textbf{頂点の自動配置}：テクスチャ撮影を行ったカメラ位置を考慮し、環境再現に必要な密度で頂点を自動配置する。
  \item \textbf{メッシュの自動分割}：配置された頂点に基づき、床面の三角形メッシュおよび壁面の四角形メッシュを自動生成する。
\end{enumerate}

図\ref{four}に示すように、ユーザーは最小限の入力だけで、
適切な密度のワイヤーフレームモデルを構築可能である。
これにより、複雑な屋内形状への柔軟な対応と、モデリング作業の効率化を両立している。
